# Free Blogger Templates

Free Blogger theme XMLs with credit locks removed so footer credits stay editable.

Vendors often ship a free build of a paid theme. The free XML installs normally, but the footer credit is frequently locked in JavaScript: edit or hide it, and the theme restores the vendor link or redirects the site. This repository publishes those free XMLs after that lock is removed. Theme features stay intact. Paid premium files are not unlocked here.

## Footer Credits

Cleaned themes use a normal credit line:

```text
Design by <original author> | Distributed by <your name or site>
```

**Design by** credits the original author. **Distributed by** is who shared the cleaned XML. You can change both. Keeping an accurate design credit is recommended.

Example on cleaned Templateify releases:

**Design by Templateify | Distributed by [Sharoon](https://github.com/sharoon7171)**

## Install on Blogger

1. Back up your current theme in Blogger → **Theme**.
2. Open the theme menu → **Restore** / **Upload**.
3. Select the downloaded `.xml` file and confirm.
4. Preview, then publish.

## Contact and Removal

Original authors or rights holders who want a theme removed or changed can reach out on GitHub:

- [Open an issue](https://github.com/sharoon7171/free-premium-blogger-templates/issues/new) — use a clear title (for example `Removal request: Everify`) and name the theme or file
- [Profile](https://github.com/sharoon7171) — for other contact options listed there

Reasonable removal and correction requests are handled as soon as practical.
